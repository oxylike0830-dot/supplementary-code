# Data Use & Access

- `data/sample/` contains **non-sensitive, anonymized** sample data solely for reproducing key figures/tables.
- Full-size datasets are **not** stored in this repository to keep the repo lightweight and to respect data policies.
- To obtain larger datasets (e.g., 1 GB OCT sample), use `scripts/fetch_data.py` which downloads from the DOI or GitHub Release asset.
- If your data involve human subjects, ensure that your IRB and anonymization policies allow redistribution.
